# mkleyn.com — the journal

A personal site drawn as a traveller's journal: a p5.brush koi pond painted on the pages of a cut-out journal photo, the
site's content on those pages, navigation as a camera move over the book. Static, vanilla ES modules, no framework.

## Run

```
npm install            # esbuild (only for the single-file lab build)
npm run dev            # http://127.0.0.1:5173 — the site in design mode (layout editor + pond panel)
```

- `/?edit=0` — the visitor view on a dev host · `/lab/boids-lab.html` — the full Painted Boids Lab
- `npm run check [-- --lab --file]` — headless end-to-end checks (needs Chrome) · `npm run build:lab` → `dist/lab.html`
- `npm run render:atlas` — pre-render the fish atlas for `assets/pond/pond.config.json` (dev server running)
- `node scripts/build-archive.mjs` — rebuild the time capsule (`v2/`) from tag `design/v2`
- `node blog/build.js` — posts in `blog/posts/*.md` → `content/blog/<slug>.html` fragments + the `/blog` spread (`cd blog && npm install` once)

## Layout

```
index.html              the shell: pond canvas, #journal-root, #book-space (nav + #spread), scripts
js/site/                routes, router, navigate (camera moves), camera, book-space, fragments, modal, main
js/pond/                the pond: createPond (pond.js), bootPond (boot.js), painter, water, book, journal, drawings,
                        school, store, residents, visitors/*  — one config object (config.js) drives everything
js/lab/                 the design-mode panel (panel.js) and the lab page's entry (main.js)
js/scene-renderer.js    the layout compositor (scene JSON → placed nodes, per breakpoint, viewport or book space)
js/layout-editor.js     its WYSIWYG editor (design mode only)
assets/pond/            pond.config.json, journal/ (compiled journal + hatch recipes), book/ (photo + page masks), atlas/
assets/scene/           _global.json (the nav) + one scene per page: placements in book space and the page's camera
content/pages/          each route's spread as an HTML fragment
css/                    site.css (pages, nav, spread, modal) · pond.css (pond) · lab.css (panel) · scene.css (compositor)
lab/                    the lab pages and the SAM/OpenCV pipelines (lab/trace) that make the journal assets
v2/ + archive/          the previous design, frozen (design iterations switcher)
scripts/                dev-server.mjs (static + /__editor API + SPA fallback), build-lab, build-archive, check, pond/*
```

## How it fits together

- **Book space.** `#book-space` is a 1536×1024 (photo px) element that `js/site/book-space.js` transforms to sit on the
  journal photo, camera included. Nodes with `space: "book"` are placed in % of it by the compositor and edited with the
  same tools, so everything on the pages moves with the book.
- **Navigation.** `js/site/routes.js` maps paths to spreads; `navigate.js` pulls the camera back over the spine, swaps the
  fragment, applies the page's scene (`sceneRenderer.loadPage`) and settles on the page's camera (`scene.camera`, in photo
  space: `{ zoom, cx, cy }`). The camera is a runtime transform in the pond (`pond.setCamera`) — never part of the config.
- **Design mode** (`?edit`, or any localhost): the layout editor saves page placement to `assets/scene/*.json`
  (Cmd-S; globals go to `_global.json`), the pond panel saves `assets/pond/pond.config.json` (Save to site). Both through
  `scripts/dev-server.mjs`; both fall back to Copy/Download without it.
- **Assets are files**, regenerated by `lab/trace/gen-journal.py` and `gen-book.py` (see `lab/trace/README.md`); the fish
  atlas is pre-rendered and used while the config still hashes to its key, else painted on the client.

## Deploy

Cloudflare Pages, straight from the branch: no build command, output `/`. SPA routes fall back to `index.html` because
there is no top-level `404.html`; `_headers` keeps `/lab/*` out of search results.
